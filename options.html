GitHub PR Watcher

Следит за вашими открытыми pull request'ами и сообщает о новых комментариях, апрувах и статусе CI.

Нужен токен только на чтение. Создать fine-grained токен. Для публичных репозиториев в «Repository access» выберите Public repositories: права выбирать не нужно, такой токен и так читает все публичные репозитории. Для приватных выберите «Only select repositories» и дайте Pull requests и Commit statuses на Read-only; организация должна разрешать fine-grained токены. Подойдёт и classic-токен: без scope для публичных репозиториев, repo для приватных.

Токен хранится только в этом профиле Chrome (chrome.storage.local) и уходит только на api.github.com.
