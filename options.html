GitHub PR Watcher

Следит за вашими открытыми pull request'ами и сообщает о новых комментариях, апрувах и статусе CI.

Нужен токен только на чтение. Создать fine-grained токен с правами Pull requests, Commit statuses, Checks (Read-only). Для публичных репозиториев выберите «Public repositories». Приватные репозитории организации требуют, чтобы организация разрешала fine-grained токены. Подойдёт и classic-токен: без scope для публичных репозиториев, repo для приватных.

Токен хранится только в этом профиле Chrome (chrome.storage.local) и уходит только на api.github.com.

По одному на строку: owner/name, ссылка на репозиторий или owner/* — все репозитории владельца. Строки с # игнорируются.
